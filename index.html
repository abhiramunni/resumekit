      Before you send it

      Six things that actually matter

      One page, always

      Freshers and under-5-years: one page. If it spills over, cut the oldest bullet first, not the newest achievement.

      Numbers beat adjectives

      "Improved load time by 40%" is proof. "Hard-working team player" is a claim anyone can type. Keep the proof, drop the claim.

      Match the job post's words

      If the post says "React", write "React" — not "a popular JavaScript library". The screening software matches exact words.

      Action verbs first

      Built, shipped, cut, led, fixed. Never start a bullet with "Responsible for", "Helped with" or "Worked on" — they say nothing.

      Honest about the degree

      Degree pending? Write "B.Tech IT, 2021–2025 (awaited)" and list what you can do. Never claim a certificate you do not hold.

      PDF, named properly

      Send a PDF named "Asha-Nair-Resume.pdf", not "Resume-final-final-v3.pdf". Print from this page — no watermark, no signup.
